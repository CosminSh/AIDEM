# Changelog

All notable changes to AIDEM are documented here.

## 1.0.0+5 - 2026-05-16

- Prepared the hackathon submission repository for review.
- Added local Gemma 4 LiteRT model setup with structured fallback behavior.
- Expanded deterministic emergency protocols and local knowledge-base coverage.
- Added scenario, guardrail, protocol, data-quality, and context-compaction tests.
- Added Android and Windows release packaging guidance.

## 1.0.0+1 to 1.0.0+4 - 2026-05-12 to 2026-05-15

- Built the Flutter emergency workflow, practice scenarios, GPS capture, voice input, image input, rescue handoff, and responsible-AI guardrails.
- Established the offline-first architecture using Riverpod, local JSON protocol assets, and on-device model integration.
