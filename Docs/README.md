# AIDEM Documentation

The repository keeps public-facing documentation compact at the root. Submission materials and historical planning notes live under this directory so reviewers can find the final artifacts without sorting through drafts.

- `hackathon/FINAL_VIDEO_SCRIPT.md` - final 3-minute video structure and narration.
- `hackathon/JUDGE_DEMO_GUIDE.md` - demo instructions to include with release files.
- `hackathon/SUBMISSION_CHECKLIST.md` - final pre-submit checklist.
- `hackathon/UPLOAD_TEMPLATES.md` - Kaggle, YouTube, GitHub, and release upload text.
- `hackathon/SUBMISSION_STATUS.md` - current verification and remaining tasks.
